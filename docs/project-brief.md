## Project Concept

### What are you building?

Estoy desarrollando una **plantilla de portfolio web personal**, pensada como una base reutilizable y expandible.  
El proyecto funciona como un ejemplo de portfolio profesional, utilizando contenido semi-inventado para mostrar cómo se pueden añadir, duplicar y escalar nuevos proyectos y secciones manteniendo la misma estructura visual y técnica.

### Who is it for?

El proyecto está orientado a **perfiles creativos y digitales** (diseñadores, ilustradores, fotógrafos y desarrolladores frontend) que necesitan una web personal flexible para mostrar su trabajo de forma visual, clara y profesional.

### Why does it matter?

Este proyecto permite entender cómo diseñar y construir una **web modular y escalable**, más allá de un portfolio estático.  
Aporta valor como base reutilizable para futuros proyectos reales y como ejercicio práctico de diseño web, estructura semántica, experiencia de usuario y accesibilidad.

## Design Direction

### Visual Style

Diseño moderno y visualmente limpio, con jerarquías claras, uso de espacios negativos y una estética cuidada orientada a portfolios creativos.

### Color Palette

- Tonos oscuros como base
- Color de acento llamativo para destacar elementos clave
- Contrastes pensados para mantener la legibilidad y la accesibilidad

### Typography

Uso de tipografías sans-serif para el texto principal, combinadas con tipografías decorativas en títulos puntuales para reforzar la identidad visual.

### Inspiration / References

- Awwwards (portfolio showcases)
- Sitios personales de diseñadores y desarrolladores frontend
- Templates modernos de portfolios creativos
